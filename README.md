# 🌍 AI Language Translation Tool

An AI-powered multilingual language translation tool developed as part of the **CodeAlpha AI Internship**.

## 📌 Project Overview

This project uses the **Facebook NLLB-200 multilingual translation model** through Hugging Face Transformers to translate text between multiple languages.

A simple and user-friendly **Gradio web interface** allows users to select source and target languages, enter text, and generate a translation.

## ✨ Features

- 🌐 Supports multiple languages
- 🤖 AI-powered translation using NLLB-200
- 🔄 Real-time text translation
- ↔️ Swap source and target languages
- 🗑️ Clear input and translation
- 💻 Simple and user-friendly Gradio interface
- 📱 Easy-to-use web-based interface

## 🛠️ Technologies Used

- **Python**
- **Hugging Face Transformers**
- **NLLB-200**
- **PyTorch**
- **Gradio**
- **Kaggle**

## 🌍 Supported Languages

The application currently supports:

- English
- Urdu
- French
- Spanish
- German
- Arabic
- Chinese
- Hindi
- Russian
- Portuguese
- Italian
- Japanese
- Korean

## 🚀 How It Works

1. The user selects the source language.
2. The user selects the target language.
3. The user enters the text to translate.
4. The NLLB-200 model processes the text.
5. The translated text is displayed in the Gradio interface.

## 🎯 Project Objective

The objective of this project is to develop an accessible AI-based translation application that enables users to translate text between multiple languages through a simple and interactive interface.
